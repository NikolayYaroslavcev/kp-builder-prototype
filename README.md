# Сборка КП — прототип

Прототип внутреннего инструмента менеджера: выбрать сделку, подобрать товары из каталога (PIM), проверить цены и скидки, получить КП в PDF и сохранить его в сделку.

Демо: https://nikolayyaroslavcev.github.io/kp-builder-prototype/

- Данные условные (`data.js`): 118 товаров, 6 сделок. Структура PIM и Битрикс24 — допущение.
- Поиск по каталогу постраничный, через одну функцию `searchCatalog` — в рабочей версии это запрос к API PIM, а не выгрузка всего каталога в браузер.
- Проверки перед формированием: нет цены, товар снят с продажи, неверное количество, скидка вне диапазона (ошибки блокируют КП); скидка выше лимита менеджера и давно не обновлённая цена (предупреждения).
- НДС 22%, цены в PIM считаются с НДС (допущение) — ставка в `data.js` (`VAT_RATE`).
- PDF — через печать браузера. «Сохранить в сделку» в демо только показывает запрос, который ушёл бы в Битрикс24.
- Черновик КП по каждой сделке хранится в браузере (localStorage).

Без сборки: статические HTML, CSS и JS. Локально — `python -m http.server 8765`, затем http://localhost:8765.

Автотест в браузере (Playwright, 17 проверок): `python tests/smoke.py` при запущенном сервере.
